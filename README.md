## Привет! 👋

Я разработчик: Telegram-боты и Mini Apps, интеграции через API, AI-ассистенты для бизнеса и веб-интерфейсы на React + TypeScript. Также пишу десктоп-приложения на C#.

**Открыт для заказов и проектной работы.**

### Чем могу помочь

- 🤖 **Telegram-боты и Mini Apps**: онлайн-запись, магазины, приём заявок, уведомления
- 🧠 **AI-консультанты**: отвечают клиентам по базе знаний компании, собирают заявки, передают диалог менеджеру
- 📊 **Автоматизация для селлеров**: отчёты и аналитика по Wildberries через API
- 🔗 **Интеграции**: CRM, Google Таблицы, платёжные системы, сторонние API
- 🌐 **Веб-приложения и сайты** на React
- 🖥 **Десктоп на C#**: утилиты и внутренние инструменты под Windows
