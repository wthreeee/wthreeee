- 📊 **Marketplace & business automation** — sales reports, stock forecasts, integrations via APIs
- 🔗 **Integrations** — CRMs, Google Sheets, payment providers, third-party APIs
- 🌐 **Web apps** with React and TypeScript
- 🖥 **Desktop tools** in C# for Windows
